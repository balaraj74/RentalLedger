# Design System

## Brand expression
Rental Ledger should feel like dependable, contemporary operations software for event-rental businesses. Keep it premium and restrained. Avoid flashy neon or gaming motifs.

## Color tokens
- `--ps-ink: #182432`
- `--ps-navy: #20364D`
- `--ps-canvas: #F6F5F1`
- `--ps-surface: #FFFFFF`
- `--ps-border: #E3E4DE`
- `--ps-muted: #64717B`
- `--ps-sage: #547A63`
- `--ps-accent: #B8754B`
- `--ps-warning: #9A6A21`
- `--ps-danger: #B54646`

## Type and layout
Use a clear sans-serif with readable sizes; headings should establish hierarchy without oversized hero typography in operational views. Use an 8px spacing rhythm. Keep content width appropriate to data-heavy tables, use 12–16px radius for surfaces, subtle borders and restrained shadows.

## Components to standardize
Button; icon button; input; select; textarea; date range control; checkbox; form field/error; card; KPI tile; badge; tabs; dropdown; dialog/sheet; toast/alert; table; pagination; empty state; skeleton; page header; filter toolbar; avatar; breadcrumb; navigation group; command/search surface; data visualization for only meaningful metrics.

## Accessibility
Use visible focus rings, 4.5:1 minimum contrast for regular text where applicable, keyboard-accessible menus/dialogs, labels, status text, reduced-motion behavior, and no color-only state communication.
