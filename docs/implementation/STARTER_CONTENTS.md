# What the starter already contains

- Agent entry points: `AGENT.md`, `AGENTS.md`, `agent.md`.
- `.agent/rules/` for product, UI engineering, security/accessibility and quality.
- `.agent/workflows/` for startup, feature work, backend integration and quality gate.
- Full product brief, frontend spec, design system, architecture, API contract, instructor-assumption note, roadmap and acceptance tests.
- Copy of the supplied SQL schema and design blueprint, when present in the generation workspace.
- Next.js App Router scaffold with design tokens, responsive shell, operational dashboard, typed demo data and route placeholders.
- Mock service interface, `.env.example`, lint/typecheck/test/build scripts, and a basic fixture test.

## Important limitation
The scaffold intentionally does not claim a complete A–Z implementation. The agent must replace route placeholders with functional workflows, connect real authentication/backend when configured, and verify build/tests. The dashboard values are sample fixtures only.
