# Rental Ledger Design System

## Visual direction
Premium, classic, calm, and operational. This is event-rental business software, not a neon/cyberpunk dashboard. Use a warm neutral canvas, deep navy/ink for structure, muted sage for positive statuses, terracotta/amber as a restrained accent, and accessible contrast.

Suggested tokens:
- ink: `#182432`
- navy: `#20364D`
- canvas: `#F6F5F1`
- surface: `#FFFFFF`
- border: `#E3E4DE`
- muted text: `#64717B`
- sage: `#547A63`
- accent: `#B8754B`
- warning: `#9A6A21`
- danger: `#B54646`

## UX requirements
- Clean information hierarchy; use whitespace instead of heavy decoration.
- Tables should be compact but readable, with consistent numeric alignment and status badges.
- Use clear terminology: Item, Package, Booking, Allocation, Return, Vendor, Customer.
- Avoid unnecessary gradients, glowing effects, glassmorphism, huge rounded cards, and ornamental charts.
- Use imagery only when it helps customers evaluate rental items/packages. Admin and vendor operational screens should prioritize data clarity.
- Responsive sidebar must collapse into a mobile navigation pattern; tables must remain usable on narrow widths.
- Show useful empty states, next actions, and filter reset behavior.
- Focus indicators and keyboard navigation are required.
