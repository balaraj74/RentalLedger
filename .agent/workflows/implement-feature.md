# Workflow: Implement a Feature

1. Read the relevant acceptance criteria in `docs/product/FRONTEND_SPEC.md` and domain definitions.
2. Define the typed DTO and service method before binding the UI to data.
3. Implement data loading, loading/error/empty states, filters/forms, and success feedback.
4. Add validation at the correct boundary.
5. Add unit/integration coverage or a reproducible manual test plan.
6. Run lint, typecheck, tests, and build where possible.
7. Update implementation status and decisions; list any mock-only behavior explicitly.
