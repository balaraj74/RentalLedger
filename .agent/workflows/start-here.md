# Workflow: Start Here

1. Read `AGENT.md`, `AGENTS.md`, all `.agent/rules/`, and relevant `docs/`.
2. Inspect the package files, route tree, SQL, and blueprint.
3. Inspect Git status before modifications.
4. Set up `docs/implementation/IMPLEMENTATION_STATUS.md` and a prioritized task checklist.
5. Verify environment requirements and run available baseline checks.
6. Start with the shell/dashboard, then complete each user journey according to `docs/implementation/ROADMAP.md`.
7. Do not stop after documenting a plan; begin implementation.
